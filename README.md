# 📚 SSA - Sistema de Seguimiento al Aprendiz

Sistema web desarrollado para gestionar el seguimiento académico de aprendices, facilitando el control de actividades, evidencias, evaluaciones, fichas e instructores en un solo lugar.

## 🚀 Tecnologías utilizadas

- Laravel
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Blade
- Bootstrap

## ✨ Funcionalidades

- 🔐 Inicio de sesión con control de roles.
- 👨‍🎓 Gestión de aprendices.
- 👨‍🏫 Gestión de instructores.
- 📋 Administración de fichas.
- 📝 Creación y seguimiento de actividades.
- 📤 Carga de evidencias.
- ✅ Calificación de actividades.
- 📊 Evaluaciones integrales.
- 📄 Generación de reportes.
- 👀 Registro de observaciones.
- 📈 Panel de administración (Dashboard).

## ⚙️ Instalación

Clonar el repositorio

```bash
git clone https://github.com/luismariomejiagarcia787-ship-it/Sistema-Seguimiento-Aprendiz-.git
```

Entrar al proyecto

```bash
cd Sistema-Seguimiento-Aprendiz-
```

Instalar dependencias

```bash
composer install
```

Copiar el archivo de configuración

```bash
cp .env.example .env
```

Generar la llave de Laravel

```bash
php artisan key:generate
```

Configurar la base de datos en el archivo `.env`.

Ejecutar las migraciones

```bash
php artisan migrate
```

Iniciar el servidor

```bash
php artisan serve
```
