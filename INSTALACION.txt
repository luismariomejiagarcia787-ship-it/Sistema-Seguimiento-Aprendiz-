  SISTEMA DE SEGUIMIENTO AL APRENDIZ — GUÍA DE INSTALACIÓN
════════════════════════════════════════════════════════════════

REQUISITOS:
  PHP >= 8.2 | Composer | MySQL/MariaDB | Node.js (opcional)

PASOS DE INSTALACIÓN:
──────────────────────

1. Clonar/copiar el proyecto y entrar al directorio:
   cd sistema

2. Instalar dependencias PHP:
   composer install

3. Copiar el archivo de entorno:
   cp .env.example .env

4. Configurar la base de datos en .env:
   DB_DATABASE=sistema_sena
   DB_USERNAME=root
   DB_PASSWORD=tu_password

5. Generar clave de la aplicación:
   php artisan key:generate

6. Ejecutar migraciones + seeder:
   php artisan migrate --seed

7. Crear enlace simbólico de almacenamiento (OBLIGATORIO para subir archivos):
   php artisan storage:link

8. (Opcional) Compilar assets:
   npm install && npm run dev

9. Iniciar el servidor:
   php artisan serve

   Abrir: http://localhost:8000
